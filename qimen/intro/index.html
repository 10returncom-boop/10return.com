奇門遁甲概論

從定義、三式、源流到學習順序，先把這套系統的邊界畫清楚。

顯示全部分類（4 個區塊）

什麼是奇門遁甲

以九宮為底、以時為單位，把天干、八門、九星、八神疊在一起的一套時空模型。

九宮時盤三式

源流與流派

從《煙波釣叟歌》到《御定奇門寶鑑》，時家、日家、法奇門、陰盤各有什麼主張。

源流流派時家

與八字、紫微比較

八字看一生的節奏，奇門看某個時刻的局勢；一個問「我是誰」，一個問「現在怎麼做」。

比較方法論

學習順序

六個階段：認盤、定局、轉盤、讀象、取用、驗盤，以及五個常見誤區。

學習六階段

入門最常卡住的地方不是口訣，而是「不知道這套系統在回答什麼問題」。先把定位弄清楚，後面每一個符號才有位置放。

一張盤就是一個時刻

同一個時辰只有一張盤，換一個時辰就換一張。它描述的是「局勢」，不是「一生的命」。

時盤局勢

四層圖層疊起來

地盤（三奇六儀）、天盤（九星）、人盤（八門）、神盤（八神），四層各有各的語言。

四盤圖層

先取用神再判斷

同一個盤問不同事，看的是不同宮位。沒有用神，就沒有判斷。

用神取象
本站一律採「時家奇門・轉盤法・拆補定局」，也就是最常見、資料最一致的一路。流派差異會在「拆補與置閏」一章說明。
建議閱讀順序：概論 → 九宮盤面 → 三奇六儀 → 八門 → 九星 → 八神 → 格局 → 定局 → 用神 → 排盤實務。急著看盤的人，可以先讀「排盤五步」再回頭補理論。
