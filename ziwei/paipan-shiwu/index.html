安星十二道步驟
驗盤用人生事件回推

輸入階段最重要的是農曆生日與時辰。國曆要換算成農曆，閏月要決定怎麼處理，時辰要用真太陽時校正。這三個只要錯一個，後面的安星全部不準。

安星階段是有固定順序的：定命宮 → 定身宮 → 定十二宮 → 定宮干 → 定五行局 → 安紫微 → 安十四主星 → 安輔星 → 安四化 → 安大限。順序反了就會卡住。

驗盤階段是用當事人的實際人生，回頭確認排出來的盤对不对。如果性格、家庭、職業、健康都對不上，第一件事是檢查生辰，而不是懷疑命理。
