命盤結構：一張盤是怎麼被排出來的

地支固定、宮名逆布、星曜分層——先看懂盤面的骨架，再看見裡面的內容。

本頁目錄／快速跳章

很多人第一次看到命盤，會被密密麻麻的星曜嚇到。其實盤面的骨架非常簡單：十二個格子固定不動，動的只有宮名與星曜。先把骨架記住，後面的學習成本會少一半。

4×4 的十二格：地支永遠不動

斗數命盤是一個正方形，外圈切成十二格，對應十二地支。固定的位置是這樣：

  • 上排（左→右）：巳、午、未、申
  • 右排（上→下）：酉、戌、亥
  • 下排（右→左）：亥、子、丑、寅（所以下排左起是寅、丑、子、亥）
  • 左排（下→上）：寅、卯、辰

中央的 2×2 空白區域，用來放基本資料：姓名、性別、國曆與農曆生日、出生時辰、五行局、命主、身主。這個區域不參與判斷，但它是驗盤的第一道線索——先確認生日時辰有沒有寫錯。

為什麼地支位置要固定？因為地支本身就帶有方位、時序與陰陽屬性。同一個宮位名稱，落在不同地支，意義就不同：命宮在子與命宮在午，即使星曜相同，表現方式也不一樣。所以斗數不是「把星放進格子」，而是星曜與地支共同決定結果。

命宮一確定，十二宮全部到位

命宮的算法是：從寅宮起正月，順數到出生月；再從那個宮位起子時，逆數到出生時辰。用公式表達就是：

命宮 = 寅 + (農曆月 − 1) − 時辰序（時辰序：子=0、丑=1……亥=11）

身宮的算法則是從出生月宮起子時順數到出生時辰，所以身宮永遠落在命宮的三方（命宮、財帛、官祿、遷移）之一，或與命宮同宮。這也是為什麼身宮常被說成「後天的著力點」。

命宮定位後，十二宮依逆時針（地支遞減）排列：命宮 → 兄弟 → 夫妻 → 子女 → 財帛 → 疾厄 → 遷移 → 交友 → 事業 → 田宅 → 福德 → 父母。這個順序是固定的，任何一派都不會改。

表 1十二宮的排列順序與對應地支（以命宮在寅為例）
順序宮名地支管什麼
1命宮寅性格、體質、人生總軸
2兄弟宮丑手足、平輩、合作
3夫妻宮子親密關係、婚姻模式
4子女宮亥子女、創造、投資
5財帛宮戌賺錢方式、現金流
6疾厄宮酉身體、壓力、情緒出口
7遷移宮申外出、環境、社會形象
8交友宮未朋友、部屬、人脈品質
9事業宮午職業性向、工作方式
10田宅宮巳不動產、家庭資產
11福德宮辰精神滿足、興趣、晚年

注意：上表只是「命宮在寅」的示例。實際命盤的宮名會隨命宮位置整組旋轉，但相對順序永遠不變。

不要從第一格開始讀

初學者最常犯的錯，是從命宮開始，一格一格往後讀，讀到最後忘記前面。比較有效率的方式，是先看結構，再看重點：

  1. 第一步：看命宮與身宮。先確定這個人的基本性格與後天著力點，相當於先認識主角。
  2. 第二步：看命宮的三方四正。命宮、遷移、財帛、官祿四格一起看，判斷這個結構是內斂還是外放、是靠專業還是靠人脈。
  3. 第三步：看四化落點。生年化祿在哪一宮（資源）、化忌在哪一宮（執著），這兩格是全盤的油門與煞車。
  4. 第四步：看提問對應的宮位。問工作看官祿，問錢看財帛，問感情看夫妻，再把該宮的三方四正拉進來。
  5. 第五步：疊大限流年。本命是常態，運限是當下。同一個宮位在特定十年被強化，才是「現在為什麼特別有感」的原因。

照這個順序，即使星曜還沒記熟，也能講出一個有結構的初步判斷；反過來，如果只背星性卻沒有結構，講出來的話就會變成一句一句互不相干的標籤。
