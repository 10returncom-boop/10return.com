體圖建構器：勾選閘門，看類型怎麼被推導出來

這是把「類型怎麼來的」攤開給你看的工具。你勾選閘門，系統只做三件事：接通通道、點亮中心、依規則判定類型與權威。

1. 勾選你的閘門

有定義　未定義　已接通通道

已選閘門：0 / 64

先勾選閘門，或按「載入範例」看一組完整示範。

2. 判定規則完全公開

這個工具不做任何神祕判斷，只執行以下四條規則：

  1. 通道接通：一條通道的兩端閘門都被勾選，該通道即接通。
  2. 中心定義：只要有任一接通的通道連到某中心，該中心即為有定義。
  3. 類型判定：
    • 九中心全未定義 → 反映者
    • 薦骨有定義 ＋ 喉嚨與動力中心連通 → 顯示生產者
    • 薦骨有定義、喉嚨未連通 → 生產者
    • 薦骨未定義 ＋ 喉嚨與動力中心連通 → 顯示者
    • 薦骨未定義、喉嚨未連通 → 投射者
  4. 權威判定（依優先順序）：情緒 → 薦骨 → 脾 → 心（連 G 或喉）→ G（連喉）→ 心智／環境 → 月亮。
「喉嚨與動力中心連通」指喉嚨經由已接通通道連到薦骨、根、情緒或心其中之一。這正是顯示者與顯示生產者的分界。

3. 三種用法

① 驗算你的完整圖。把你手上那張圖的所有閘門勾起來，看看這裡推導的類型是否與你的圖一致。若不一致，很可能是有閘門漏勾，或那張圖本身用了不同的判定慣例。

② 做情境模擬。勾一組你最在意的通道，看看它會點亮哪些中心。例如只勾 20-34，你會看到喉嚨與薦骨同時亮起——這就是顯示生產者的最小結構。

③ 理解「空白」。把你實際的閘門勾完，看哪些中心是白色的。那些就是你最容易接收別人能量、也最容易做錯決定的地方。

4. 這個工具不能做什麼

  • 它不會幫你算出你「應該」勾哪些閘門——那需要完整星曆。
  • 它不做爻線分析（六條爻線的差異需要完整啟動資料）。
  • 它不做流年、流日、合圖。
  • 它不會告訴你「所以你適合什麼工作」。
工具的價值在於讓你看見推導過程，而不是取代你自己的判斷。
